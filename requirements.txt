# =====================================================
# INSTALLATION STEPS
# =====================================================

# Step 1: Install Node.js
# Download and install from: https://nodejs.org/
# Verify: node --version && npm --version

# Step 2: Clone/Download Project
# git clone <repository-url>
# cd ai-interview-master

# Step 3: Install All Dependencies
# npm install

# Step 4: Configure Environment Variables
# Copy .env.example to .env
# Fill in Supabase credentials
# Fill in SMTP credentials

# Step 5: Setup Database
# Run database/schema.sql in Supabase SQL Editor
# Create admin user (see database/admin_setup.sql)

# Step 6: Test Configuration
# npm run test:smtp

# Step 7: Start Application
# .\start-servers.bat
# OR
# npm run dev (frontend)
# npm run server (backend)

# =====================================================
# VERIFICATION COMMANDS
# =====================================================

# Check Node.js version
# node --version

# Check npm version
# npm --version

# List installed packages
# npm list --depth=0

# Check for outdated packages
# npm outdated

# Update packages (if needed)
# npm update

# =====================================================
# TROUBLESHOOTING
# =====================================================

# If npm install fails:
# 1. Delete node_modules folder
# 2. Delete package-lock.json
# 3. Run: npm cache clean --force
# 4. Run: npm install

# If port conflicts occur:
# - Backend uses port 3001
# - Frontend uses ports 8080-8083
# Kill processes using these ports or change PORT in .env

# If SMTP fails:
# - Verify credentials in .env
# - Test with: npm run test:smtp
# - Check firewall settings
# - Try different SMTP provider
